# Avatar Surface Color Synchronizer

**VRChat Avatar 肤色同步与颈线融合工具**。当脸和身体使用不同材质，导致下巴与脖子之间出现明显色差时，可以让一侧以另一侧为参考，只在接缝附近调色，再自然过渡回原肤色。工具会在 Unity 编辑器中重渲染比较效果；确认后才需要生成和替换材质，不会覆盖原始贴图或材质文件。

## 能做什么

- **仅融合颈线（默认）**：让色差沿接缝附近逐渐减弱，保留带外的原肤色。支持自动宽度或手动指定过渡距离。
- **整体校色（会改全身）**：调整所选材质的整体肤色，适合想同时改变手臂、躯干等同一材质覆盖区域的情况。只想修颈线时不要选它。
- **单向同步或两侧取中间色**：「原材质向目标同步」只改**原材质**组，目标是参考；「两组材质统一至中间色」会尝试调整两组。每组可以包含多个材质槽。
- **预览与撤回**：支持原始／调整后对比、颈线特写、热力和不同灯光。输出独立贴图、材质副本和生成记录，可以按记录恢复原材质。

## 参数怎么调

| 参数 | 实际作用 |
| --- | --- |
| **自动融合宽度** | 让工具根据接缝计算宽度。旧版滑块的 `0` 也是自动，不代表最窄。 |
| **融合宽度 (mm)** | 控制颜色从接缝附近衰减回原肤色的距离，不决定改哪一侧。「仅融合颈线」手动最小 **15 mm**；过窄会造成一串色点，旧设置低于下限时会停止生成，不会自动加宽。 |
| **局部强度** | 控制颈线校正量。觉得接缝附近颜色过重，先降低强度，不必一味缩短宽度。 |
| **平滑颈线** | 让沿接缝的校正量更均匀，不改变过渡长度，也不是模糊原贴图。 |
| **同步强度／明度／色彩** | 分别控制总校正量、亮度校正和色彩校正。可以先用默认值，再按预览微调。 |
| **妆容保护** | 降低覆盖层区域的校正。需要更精细的控制，可以在 **材质** 页设置皮肤遮罩和保护遮罩；两者读取 R 通道，白色分别表示允许调整和保护。 |
| **选材距离** | 用于寻找相接的材质，不是过渡宽度。通常保持默认即可。 |

## 输出、应用与恢复

- 默认输出到 `Assets/AvatarSurfaceSyncGenerated`。每次新生成会创建独立目录，其中有贴图、`.mat` 材质副本和 `Assignments.asset` 生成记录。
- **仅融合颈线**保留源贴图尺寸，并用 Unity 贴图资产（`.asset`）保存各级 Mipmap；不输出 PNG 是正常的。**整体校色**输出 PNG，可在输出页选择分辨率。
- **生成资源**不替换场景材质。要之后应用，把 `Assignments.asset` 拖到 **输出 → 生成记录**，然后点 **应用本记录**。
- 想撤回时选择该生成记录，点 **恢复原材质**；也可以用 Unity Undo 撤回引用的替换。恢复后生成的文件仍留在输出目录。如果已经应用了旧版出斑或改到下巴的结果，先恢复原材质，再重新分析和计算。

## 常见问题

**自动选材失败，或者一直没有结果？** 先确认选的是场景里的 Avatar 根节点，脸和身体选的是贴着同一条颈线的材质槽。自动失败时可以手动选。再看窗口底部的 **查看详情**，区分采样不足、带外变化和材质不适合安全烘焙。不建议为了出结果切到整体校色。

**为什么某些 lilToon 脸部改了主贴图但看不出来？** 可见肤色可能主要来自第二主贴图。在「仅融合颈线」下，如果主贴图方案未通过复核，工具会尝试在符合条件的静态 UV0、普通混合等材质上局部调整第二主贴图，保留其 Alpha，不需要关闭妆容层。详情会标出 **颈线融合 · 第二主贴图**。

**找不到「处理范围」，或者导入后界面还是旧的？** 等 Unity 编译完成后重开窗口。若 Console 有 `ShinanoSyncProbe.cs` 给 `SeamOnly` 赋值的 `CS0200`，使用包含兼容修复的这版安装包。`.omochi` 多个导入器抢占同一扩展名是单独的工程冲突，与这条 C# 编译错误无关。

## 适用范围与限制

- 面向 **VRChat PC Avatar** 的编辑工作流，适配 Unity Standard、常见 Unity Unlit、部分 lilToon 配置，以及本工程使用的 DewSkin。不会把 PC Shader 转换成 Android／Quest Shader。
- 工具按当前姿态、贴图和材质状态采样；材质属性块、动态 UV、特殊 Shader、重叠 UV 或没有可见的可信接缝都可能限制输出。融合只处理颜色，不修改模型、法线、骨骼或 UV。
- 动画和换装可能覆盖材质槽。Lilycal Inventory 在同一槽、相同来源主贴图和 UV 的条件下可以沿用校正；第二主贴图的局部校正不会套用到其他独立妆容材质。应用后请切换常用妆容和衣装复查。
